States

working
Claude is busy. Typing on a laptop is classic.

done

drag

wave

jump
Plays once when a question arrives.
look
Idle fidget: glance around.
stretch
Idle fidget: a big stretch.

Missing states fall back to ones you have (for example sleep → idle), so a pet with just idle and working already works.

Claude Code connection

…

Promptagotchi connects through Claude Code hooks: small entries in ~/.claude/settings.json that send each session event to the pet on this Mac (127.0.0.1 only). No MCP server or account is involved. Without hooks the pet still sees every session from Claude’s status files.

    Pet

    Right-click the pet for quick pet and size changes.

    Shortcuts

    Show / hide the pet
    Whip mode on / off

    Click Change, then press the keys you want: a ⌘, ⌃ or ⌥ combination plus a key. Esc cancels.

    Whip

    Turn it on and off with the shortcut above, then bring your cursor near the pet. Once you’re close enough, the lash swings at the pet by itself, with a whiplash smear on fast swings. When it lands, it cracks, the pet flinches, and it goes into ⚡ Hustle mode for a while. Every hit adds time. Misses are silent.

    Hustle mode is only the pet’s animation. It types and moves faster on screen. It never touches Claude, your sessions or your code: nothing about how Claude works changes. (For a faster Claude, Claude Code has /fast.)
